KGet options

Downloads

Files are saved in KGet's download directory (daemon.download_dir in KGet's config, default ~/Downloads).

Intercept browser downloads

Needs the “downloads” permission (asked when you turn this on). If KGet is unavailable the browser downloads the file itself. Downloads that need a form submission (POST) cannot be handed over.

Cookies

Off by default. Lets KGet download files that need you to be logged in. Only the cookies for the download's URL are sent, as a Cookie header, to your local KGet. Needs the “cookies” permission and access to sites (asked when you turn this on).
